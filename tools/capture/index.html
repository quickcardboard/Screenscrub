ScreenScrub capture

Shows each test image full-screen for a few seconds. Photograph the screen while it plays (hold the shutter for a burst and move slowly). Every slide has markers in its corners, so the photos line up with the originals automatically.

  • Space or tap: pause / resume   ← →: previous / next
  • + −: slower / faster (now s per slide)
  • On a TV, set picture size to "Just Scan", "Screen Fit" or "1:1" so nothing is cut off.
  • Turn screen auto-dimming off, or keep it plugged in.
